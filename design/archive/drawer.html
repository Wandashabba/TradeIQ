03 · Drawer — phone onlyThe overlay survives only where width genuinely forces it. Same rows, same order, same counts.

Grouped by what you came to do

Nineteen flat destinations is a menu you have to read. Three verbs — Operate, Insight, Configure — is a menu you can scan.

The active row is a rule, not a pill

A 3px left rule plus a weight change. No rounded chip, no fill, no glow — it reads as position, which is what it means.

Counts earn color by consequence
